# goosemarklint

goosemarklint is an opinionated Markdown linter and formatter, written in Goose, that checks Markdown for ASD-STE100 and common style rules.

It parses CommonMark and GitHub Flavored Markdown, and it has profiles for README.md, SKILL.md, AGENTS.md and CLAUDE.md.

```sh
goosemarklint check <paths>
goosemarklint fmt <paths>
```

The tool is not usable yet.
