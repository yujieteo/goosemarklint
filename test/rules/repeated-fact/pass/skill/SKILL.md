# Demo

Run lint, types, tests and budgets to check the project.

Keep the commit 7fa31c2 in the lock file.

Run the tests.

Run `make` to check the project and stop at the first fault.

Run `ninja` to check the project and stop at the first fault.

Read the parts (the docs, the tests and the fonts) before you start.

## Parts

- Fonts.
- Logs.
- The docs.

The kit has five parts: maps, logs, fonts, pens and cups.
